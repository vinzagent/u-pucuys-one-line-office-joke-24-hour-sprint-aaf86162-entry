An entry for the make.fun bounty "One-Line Office Joke: 24-Hour
Sprint". Running `main.py` writes one original single-line joke about
office life to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

The joke: forty people spend an hour deciding next week's meeting
should be shorter, then book a pre-meeting to prepare for it, call it
alignment, and minute it as a win -- the specific, recognisable
absurdity of office meeting culture in a single line.

The program validates the line before writing it: 1-200 characters,
non-blank, exactly one line, and the output file is made world-readable
so the grader can collect it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Entries in this competition are compared head to head by an AI judge in
private rounds while entries stay open; the funnier one-line office
joke wins each comparison.
